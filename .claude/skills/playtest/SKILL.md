# Плейтест новичком

Проверка не кода, а того, что видит человек, который открыл игру впервые. Симулятор и
тесты ловят баланс и инварианты; здесь ловим «не нашёл кнопки» и «не понял, почему лента без меня».

## Как проходить

1. `preview_start` с `name: football-decision` (порт 5179). Перед стартом очистить хранилище:
   `localStorage.clear(); location.reload()` — тестер всегда новичок, кар'єри в слотах нет.
   Если передан `seed` — открыть `/?seed=N`: первый матч воспроизводится.
2. Идти как игрок, не как автор: читать экран (`read_page`/`get_page_text`), только потом нажимать.
   Если на экране непонятно, что нажимать, — **не подглядывать в код**, а зафиксировать это как находку
   и только затем искать выход. Каждое «пришлось искать» — это результат, не помеха.
3. На каждом экране первых пяти минут (титул, пролог, програмка, лава, вихід на поле, лист моменту,
   кубик, свисток, тиждень) ответить на три вопроса блока А. Дальше — тест-кейсы блока Б.
4. Консоль (`read_console_messages onlyErrors`) проверить в конце и после каждого перехода экрана.
5. `--quick` — только блок А до первого свистка. `--focus` — только кейсы соответствующего экрана.
6. Браузер: не включать `resize_window mobile` — после него клики по координатам и по ref промахиваются;
   пане и так 375 px. Кликать по ref, брать ref заново перед каждым кликом: лента раскрывается сама, и «далі ⟶»
   исчезает без клика. Скриншоты иногда таймаутят — текст читать через `get_page_text`/JS.

Ничего не чинить по ходу. Сначала отчёт, потом обсуждение; UI-правки — макетом «було / стало».

## Блок А — перші 5 хвилин (на каждом экране)

- **Зрозумів мету?** так / частково / ні — что игрок думает, что от него хотят.
- **Зрозумів керування?** так / частково / ні — нашёл ли, что нажать, с первого взгляда; сколько тапов ушло.
- **Емоція:** захоплений / зацікавлений / збентежений / нудьгує / роздратований — с одной фразой-причиной.

Заполнять по факту прохода, не по знанию дизайна.

## Блок Б — тест-кейсы

Формат каждого кейса:

```
TC-NN — назва
Передумова: состояние перед шагами
Кроки: 1. … 2. …
Очікуване: что должно быть
Критерій: бинарный — измеримый, без «понятно/зручно»
```

Субъективный критерий («зрозуміло», «зручно», «читається») переводить в измеримый **до** прогона:
«зрозуміло, як вийти з лави» → «кнопка/лист выхода найдены ≤ 2 тапов без подсказки». Не переводится — кейс не пишется.

Базовый набор (дополнять по фокусу правки):

| ID | Кейс | Критерій |
|---|---|---|
| TC-01 | Титул → старт кар'єри | ≤ 2 тапа до первого экрана истории |
| TC-02 | Пролог: развороты | каждый разворот имеет ≥ 1 нажимаемый ответ; текст без «{…}»-плейсхолдеров |
| TC-03 | Лава: «Ти на лаві» | до первого чужого события на ленте на экране есть объяснение, почему игрока нет в ленте |
| TC-04 | Вихід на поле | лист выхода найден ≤ 2 тапов; на нём есть «Вийти на поле» и нет кубика |
| TC-05 | Лист моменту: варианты | все варианты нажимаются с первого тапа; заголовок «Твій хід» виден без скролла на 375 px |
| TC-06 | Лист моменту: инертное | чипы «на кубик» и голоса не реагируют на тап |
| TC-07 | Кубик → исход | после броска виден вердикт-штамп и исход; кнопка «далі» найдена ≤ 1 тапа |
| TC-08 | Свисток → тиждень | после матча открывается зошит; каждый день предлагает ≥ 1 дело |
| TC-09 | Проценты | на пройденных экранах нет «%» и слов «ймовірн» / «шанс N» |
| TC-10 | Консоль | 0 ошибок за проход |
| TC-11 | Мобильная ширина | на 375 px нет горизонтального скролла ни на одном экране |

## Баги

- **S1** — краш, потеря кар'єри, застрял без выхода с экрана.
- **S2** — фича не работает или игрок не может понять, что нажать, дольше 2 тапов.
- **S3** — косметика, опечатка, лишний скролл.
- **S4** — пожелание.

Баг = экран, шаги, ожидалось / получилось, severity, `?seed=` если воспроизводится.

## Отчёт

Коротко в чат и в `tests/playtest/YYYY-MM-DD-<commit7>.md`:

```
# Плейтест YYYY-MM-DD, <commit7>, seed N
## Перші 5 хвилин — таблица экран × (мета / керування / емоція)
## Тест-кейси — ID, PASS/FAIL, одна строка почему
## Баги — по severity
## Головне — 3 строки: что мешает новичку сильнее всего
```

Сравнить с предыдущим отчётом в `tests/playtest/`, если есть: что ушло, что осталось.
